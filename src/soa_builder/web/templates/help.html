Steps to Create an SoA Matrix

  1. Create a new Schedule of Activties on the landing page.

    • Study Name
    • Study ID
    • Study Label
    • Study Description
    • Create Study

  2. Create Schedule of Activities Matrix on Study Landing Page

    • A basic Schedule of Activity Matrix can be created on the landing lage once a study is created.
    • Add Scheduled Instances to create coluuns for the SOA Matrix
    • Add Activites to create rows for the SOA Matrix
    • Selecting a cell in the Matrix will add a 'X' indicating the Activity is assigned to the Scheduled Instance
    • Biomedical Concepts can now be assigned to an Activity

    This only creates a rudimentary SOA Matrix. More detail can be added using the links in the navigation menu.

    Links are only available once a study SOA has been chosen.

  3. Create Study Timing

    • Click Study Timing in the navigation menu
    • There are four configurations available
      • Schedule Timelines
      • Scheduled Activity Instances
      • Scheduled Decision Instances
      • Condition Assignments
      • Timings

  4. Create Epochs

    • Click Epochs in the navigation menu

  5. Create Arms

    • Click Arms in the navigation menu

  6. Create Elements

    • Click Elements in the navigation menu

  7. Associate Study Epochs and Arms with Elements

    • Click Study Cells

  8. Create Encounters

    • Click Encounters in the left sidebar

  9. Transition Rules for Encounters and Elements can also be defined

    • Click Transition Rules in the menu navigation menu

  10. USDM JSON can also be generated

    • Click Generate USDM JSON in the menu navigation menu

    Partial JSON can be generated for the different USDM classes.

    The full USDM JSON is not complete. Not all classes required for USDM conformance can be generated with the attributes set in the SOA Workbench

  11. Return to the Edit Page

    • Go back to the Edit Page
    • The Matrix will now be displayed with Activities as rows and Instances as columns
